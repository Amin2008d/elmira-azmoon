# قالب المیرا آزمون

قالب HTML کامل سایت سالن زیبایی المیرا آزمون، بر اساس هویت بصری برند: ۱۸ صفحه، فارسی و راست‌به‌چپ، Tailwind CSS v4، حالت روشن و تیره.

## صفحه‌ها

| بخش | صفحه‌ها |
|---|---|
| سالن | `index.html` · `booking.html` (لیست خدمات) · `service-single.html` · `gallery.html` |
| فروشگاه | `shop.html` · `product-single.html` · `cart.html` · `checkout.html` |
| آموزشگاه | `academy.html` · `course-single.html` · `enroll.html` |
| عمومی | `blog.html` · `blog-single.html` · `about.html` · `contact.html` · `auth.html` · `account.html` · `404.html` |

## ساختار

```
elmira-theme/
├── *.html                 ← خروجی نهایی (ساخته‌شده؛ مستقیم ویرایش نکنید)
├── assets/css/theme.css   ← توکن‌های رنگ، کامپوننت‌ها و افکت‌ها
├── assets/js/theme.js     ← همهٔ رفتارها و میکرواینتراکشن‌ها
├── assets/img/            ← تصاویر محلی (WebP)، ساخته‌شده توسط build.py
├── assets/brand/          ← لوگو، مونوگرام، favicon
└── _src/
    ├── build.py           ← اسکریپت ساخت
    ├── partials/          ← head، سربرگ، فوتر و اجزای شناور مشترک
    └── pages/             ← محتوای هر صفحه
```

برای تغییر یک صفحه، فایل آن را در `_src/pages` ویرایش کنید و بعد این دستور را اجرا کنید:

```bash
python3 _src/build.py            # ساخت صفحه‌ها + دانلود تصاویری که هنوز در assets/img نیستند
python3 _src/build.py --prune    # همان، و پاک کردن تصاویری که دیگر استفاده نمی‌شوند
```

### تصاویر

همهٔ تصاویر محلی‌اند و از `assets/img/` لود می‌شوند. در صفحه‌ها هر تصویر به شکل `@@نام,عرض,ارتفاع@@` نوشته می‌شود، مثلاً `@@serum,600,600@@`. نام‌ها در جدول `IMAGES` داخل `build.py` به عکس‌های Unsplash وصل‌اند. اسکریپت ساخت برای هر اندازه‌ای که استفاده شده یک فایل WebP با همان برش می‌سازد (`serum-600x600.webp`). اگر فایل نباشد، فقط همان یک بار از اینترنت دانلودش می‌کند.

برای گذاشتن عکس واقعی سالن، فایل مربوط را در `assets/img` با عکس خودتان (همان نام و ابعاد) جایگزین کنید. اگر هم می‌خواهید یک عکس در همهٔ اندازه‌ها عوض شود، شناسهٔ آن را در جدول `IMAGES` تغییر دهید، فایل‌های قدیمی آن نام را پاک کنید و دوباره بسازید.

## تنظیمات

- **سامانهٔ نوبت‌دهی:** رزرو نوبت در سایت انجام نمی‌شود. همهٔ دکمه‌هایی که `data-booking` دارند به یک آدرس لینک می‌شوند و در تب جدید باز می‌شوند. آدرس را در `assets/js/theme.js` و در متغیر `BOOKING_URL` بگذارید.
- **رنگ‌ها:** متغیرهای بالای `theme.css` (`:root` برای حالت روشن و `html.dark` برای حالت تیره).

## هویت بصری

از پوشهٔ `Elmira azmoun` در ریشهٔ پروژه گرفته شده:

| نقش | توکن | مقدار |
|---|---|---|
| زرشکی برند | `--wine` | `#7F264B` |
| صورتی پودری برند (دکمهٔ اصلی) | `--blush` | `#D2A1A1` |
| زرشکی خیلی تیره (متن روی صورتی، دکمهٔ تیره) | `--deep` | `#3D1128` |
| گرادیان بنرها | `--grad` | از `#2A0B1B` تا `#9C4366` |

فایل‌های `assets/brand/`:

- `mark.png`: مونوگرام EA
- `logo.png`: لوگوی کامل با «ELMIRA AZMOUN»، سال ۲۰۲۴ و شعار
- `icon-32.png` و `icon-180.png`: favicon و آیکون iOS، از روی تصویر پروفایل برند
- `og.jpg`: تصویر اشتراک‌گذاری در شبکه‌های اجتماعی

لوگوها به‌صورت ماسک CSS استفاده می‌شوند (کلاس‌های `logo-mark` و `logo-full`)، پس رنگشان همان رنگ متن والد است. برای عوض کردن رنگ کافی است کلاس رنگ متن را تغییر دهید، مثلاً `text-blush` یا `text-wine-ink`.

`og:image` آدرس نسبی دارد. پس از انتشار، آن را در `_src/partials/head.html` به آدرس کامل دامنه تغییر دهید.
- **Tailwind:** از CDN و به‌صورت کامپایل در مرورگر (`@tailwindcss/browser@4`) لود می‌شود. پیش از انتشار واقعی بهتر است به CSS ساخته‌شده تبدیل شود.

## افکت‌ها و تعامل‌ها

پردهٔ انتقال بین صفحه‌ها، نشانگر سفارشی ماوس، دکمه‌های مغناطیسی، کارت‌های سه‌بعدی، تیتر کلمه‌به‌کلمه، ورود به دید با برش (clip)، پارالاکس، نوار متحرک، شمارنده‌ها، تغییر تم با موج دایره‌ای، سربرگ هوشمند، نوار پیشرفت اسکرول، پرواز محصول به سبد، قلب علاقه‌مندی، اعلان‌ها، کشوی منو و سبد، آکاردئون، تب با خط لغزان، فیلتر و مرتب‌سازی، لایت‌باکس، اسلایدر قبل و بعد، بزرگ‌نمایی تصویر محصول، لغزندهٔ قیمت، کد یکبار مصرف، بارگذاری فایل با پیش‌نمایش، اعتبارسنجی فرم و فهرست مطالب فعال.

همهٔ حرکت‌ها با `prefers-reduced-motion` خاموش می‌شوند. بدون جاوااسکریپت هم همهٔ محتوا دیده می‌شود.
